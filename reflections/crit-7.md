# Crit 7 reflection

My main breakthrough was learning to identify a problem by looking at an existing system from a wider angle before narrowing down the details. Programs and Courses already contains a lot of useful information. The difficulty is in how students have to use it: they connect degree requirements, commencement years, specialisations and course choices themselves. I wanted to understand what people expect the platform to help them do, and where that expectation is not being met.

That changed the direction of this project. The aim became helping students understand how a course fits their own situation, while preserving the useful catalogue that already exists. Thinking about how an improvement could fit into the existing system mattered as much as deciding what to build. A system should continue operating well while meeting the needs that led to the change.

This work also clarified the kind of developer I want to become. Being a developer is not about continually showcasing development skills or inventing features. It is about understanding user needs and designing a system around them. I want to keep that wider view long enough to choose the right problem, then use the details to make the response useful. For this planner, explaining what counts—and where a student still needs confirmation—serves that purpose.
